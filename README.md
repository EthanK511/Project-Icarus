# Project-Icarus
Test Rocket In Prep for ARC 2027
This is our wind up to building a full scale rocket for ARC 2027. We are using this small rocket to gain team expierience with the fundamentals of model rocket construction. We are using complicated build techniques like epoxy fin fillets, custom laser cut motor mounts.
It uses esp32 c3 module to measure altitude and record flight data.
We are using a c6-5 motor to propel the rocket to about 600ft.
